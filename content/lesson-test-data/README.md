# ArcTester static lesson test packages

These are fictional, original sample lesson packages for testing the Admin Lesson Studio static-import flow and student lesson player.

## Import
1. Open the web admin **Lesson Studio**.
2. Choose **Import lesson package** and select one JSON file below.
3. Review the imported draft, save if needed, then publish manually to test student visibility.
4. Prepare/upload audio separately for scene narration if testing stored audio playback.

Each file is a single import package matching [STATIC_LESSON_IMPORT_FORMAT.md](../../docs/STATIC_LESSON_IMPORT_FORMAT.md). Imports create unpublished drafts; these fixtures do not seed or publish themselves.

| File | Subject/topic | Focus |
|---|---|---|
| [c-pointers.lesson.json](c-pointers.lesson.json) | C Programming / Pointers | text + step sequence + checkpoint |
| [dbms-normalization.lesson.json](dbms-normalization.lesson.json) | DBMS / Normalization | diagram + dependencies + checkpoint |
| [digital-logic.lesson.json](digital-logic.lesson.json) | Digital Electronics / Boolean Algebra | equation + step sequence + checkpoint |

All lesson content is sample material. No student data, answer keys, executable markup, or external media URLs are included.
